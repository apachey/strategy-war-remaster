# Strategy War Remaster

Фанатський ремайстер мобільної стратегії **Strategy War** (Jiří Mikula / Redboss, 2004) для Mac.

Статус: **етап 0** (середовище). Гра поки показує місії оригіналу у вигляді "сірих коробок".

## Як запустити на Mac

1. Відкрий вкладку **Actions** у цьому репозиторії, вибери останній зелений запуск **CI**.
2. Унизу в **Artifacts** завантаж `StrategyWarRemaster-macOS-arm64` і розпакуй .dmg.
3. Перетягни застосунок у **Applications**.
4. Застосунок не підписаний сертифікатом Apple, тому при першому запуску: клік правою кнопкою → **Відкрити** → **Відкрити**.
   Якщо macOS пише, що файл пошкоджено, виконай у Терміналі:
   `xattr -cr "/Applications/Strategy War Remaster.app"`
