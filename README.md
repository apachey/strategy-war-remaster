# Shardfall, a Strategy War remaster

Фанатський ремайстер мобільної стратегії **Strategy War** (Jiří Mikula / Redboss, 2004) для Mac.

Статус: **версія 1.1.0**. Уся кампанія з 21 місії, скірміш на 7 мапах проти компʼютера та гра вдвох за одним Mac.
Нова піксельна графіка трьох рас, музика й звуки, мінікарта, збереження, українська й англійська. У 1.1: головний
екран, піксельний інтерфейс і портрети, окремі башти, черга виробництва, жива мапа, голоси юнітів і нова музика.

**Як встановити й запустити:** [docs/INSTALL.md](docs/INSTALL.md) (там же інструкція для друзів).

## Керування

| Дія | Як |
|---|---|
| Вибрати | ЛКМ по юніту чи будівлі; рамка мишею вибирає кілька танків; Shift додає |
| Наказ | ПКМ: по ворогу атакувати, по жовтому полю (харвестером) збирати, по своїй будівлі охороняти, по землі їхати |
| Будувати | Вибери штаб, натисни будівлю внизу, клацни на мапі (стіни ставляться поспіль, ПКМ або Esc скасовує) |
| Танки | Вибери завод і натисни тип танка |
| Загони | Cmd+1…9 запамʼятати, 1…9 вибрати |
| Інше | H штаб, S стоп, Пробіл пауза, колесо або +/− зум, F уся мапа, стрілки або край екрана прокрутка |
| Мінікарта | Правий верхній кут: клацни або веди мишею, щоб перейти |
| Налаштування | ⚙ вгорі: гучність музики й звуків, мова, версія гри |

Будь-яку місію можна відкрити кнопкою **Місії** вгорі.

## Як отримати гру

Кожна нова версія на `main` сама стає релізом: вкладка **Releases** у цьому репозиторії, файл
`Shardfall-<версія>.dmg`. Він працює на будь-якому Mac (Apple Silicon і Intel) з macOS 12 чи новішою.
Репозиторій приватний, тож друзям цей .dmg треба передати напряму (AirDrop, месенджер, хмара) разом із посиланням на
[інструкцію](docs/INSTALL.md) або її текстом: він же стоїть в описі релізу. Збірка кожного запиту на зміну лежить у
**Actions → CI → Artifacts → Shardfall-macOS**.

Щоб випустити нову версію, досить підняти `version` в `apps/desktop/package.json`.
