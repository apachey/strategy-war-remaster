# Strategy War Remaster

Фанатський ремайстер мобільної стратегії **Strategy War** (Jiří Mikula / Redboss, 2004) для Mac.

Статус: **етап 1** (прототип у "сірих коробках"). Усі 21 місія оригіналу граються: збір ресурсу, будівництво,
танки, бій, туман війни, перемога й поразка. Графіка поки умовна, справжня буде на етапі 2.

## Керування

| Дія | Як |
|---|---|
| Вибрати | ЛКМ по юніту чи будівлі; рамка мишею вибирає кілька танків; Shift додає |
| Наказ | ПКМ: по ворогу атакувати, по жовтому полю (харвестером) збирати, по своїй будівлі охороняти, по землі їхати |
| Будувати | Вибери штаб, натисни будівлю внизу, клацни на мапі (стіни ставляться поспіль, ПКМ або Esc скасовує) |
| Танки | Вибери завод і натисни тип танка |
| Загони | Cmd+1…9 запамʼятати, 1…9 вибрати |
| Інше | H штаб, S стоп, Пробіл пауза, колесо або +/− зум, F уся мапа, стрілки або край екрана прокрутка |

Будь-яку місію можна відкрити кнопкою **Місії** вгорі.

## Як запустити на Mac

1. Відкрий вкладку **Actions** у цьому репозиторії, вибери останній зелений запуск **CI**.
2. Унизу в **Artifacts** завантаж `StrategyWarRemaster-macOS-arm64` і розпакуй .dmg.
3. Перетягни застосунок у **Applications**.
4. Застосунок не підписаний сертифікатом Apple, тому при першому запуску: клік правою кнопкою → **Відкрити** → **Відкрити**.
   Якщо macOS пише, що файл пошкоджено, виконай у Терміналі:
   `xattr -cr "/Applications/Strategy War Remaster.app"`
